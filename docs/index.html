GOOD TO KNOW

Questions,
answered.

Is Exomina really free?+

Yes. Exomina is open source under Apache-2.0: use it, read the code, fork it and distribute your own versions, including commercial ones, with the required notices. Your AI provider’s subscriptions, API charges and terms are separate.

Do I need a paid AI subscription?+

It depends on the connection you choose. Subscription connections use your own eligible account, API connections are billed by the provider, and local models need their own server and model download. Exomina does not include bundled AI access.

Which AIs can I connect?+

ChatGPT, Claude, Gemini, Grok and other supported connections, including local-model servers. ChatGPT and Grok clients are included. Claude connects through your own official Claude Code client; Gemini and Muse need their clients installed separately.

Do I need to import anything first?+

No. Install, connect a provider and start with an empty library. Importing earlier conversations or memories is entirely optional.

Is it safe to let an AI edit files and run commands?+

You decide per chat. Start with Ask so actions wait for your approval, choose which folder it may use and switch individual tools off. Commands run with your own account’s access, so choose the workspace accordingly.

Does everything work on every platform?+

The core app runs on Windows, macOS and Debian/Ubuntu. Some features vary: voice features are documented for Windows, media depends on the provider, and native Windows EXE analysis needs Ghidra and a full Java JDK.

How do updates and bug reports work?+

Updates are manual during the beta: install a newer release over the existing app to keep your library, and keep a backup. Report problems as a GitHub issue with your system, app version and steps to reproduce.
