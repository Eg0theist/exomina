GOOD TO KNOW

A few things
before you start.

Is Exomina free and open source?+

Exomina is open source under Apache-2.0. You can use it, explore the code, fork it and distribute your own versions, including commercial projects, with the required notices. Your AI provider’s subscriptions, API charges and service terms are separate.

Do I need a paid AI subscription?+

It depends on the connection you choose. Supported subscription connections use your own eligible account; API connections are billed separately by the provider. Local models need their own server and model download. Exomina does not provide unlimited or bundled AI access.

Which providers can I connect?+

ChatGPT, Claude, Gemini, Grok and other supported connections, including local-model servers. The beta includes ChatGPT and Grok clients. Claude is opt-in through your official Claude Code client; Gemini and Muse require separate clients. Connection cards explain setup and availability.

Do I need to import anything first?+

No. Install, connect a provider and start chatting with an empty library. Importing earlier conversations or memories is entirely optional.

Does everything work on every platform?+

The core app has Windows, macOS and Debian/Ubuntu installers. Individual features vary: voice features are documented for Windows, media depends on the connected provider, and supported native Windows EXE analysis requires Ghidra and a full Java JDK. See the platform and provider guides for the current scope.

How do updates and bug reports work?+

Updates are manual in this public beta. Install a newer release over the existing app to keep your library, and keep a backup. For problems, open a GitHub issue with your operating system, app version and steps to reproduce. The release validation document records tested behavior and remaining limits.
