A FEW THINGS WORTH KNOWING

Before you
make yourself at home.

What does “free” include?+

Exomina itself is free and open source under Apache-2.0. Your provider subscriptions, API charges, hosting and other external services are separate. Exomina does not include AI credits or unlimited model access.

Which AI connections can I use?+

Supported connections include ChatGPT, Claude, Gemini, Grok and local model servers. Some use your eligible subscription; others use separately billed APIs. Certain connections need an official client installed. Check the installation guide for current requirements.

Can I start without importing my old chats?+

Yes. Connect an AI and begin with an empty library. Importing previous conversations and memories is optional.

Can it really build an app or replace a SaaS workflow?+

It can work with files, code, terminals and available tools to help build and test software. Scope matters: integrations, data migration, security, hosting and ongoing maintenance still need attention. Treat the result as a project to verify, rather than a guaranteed one-prompt replacement.

Does every feature work on every platform?+

The desktop app has Windows, macOS and Debian/Ubuntu downloads. Voice, media, remote access and analysis features have their own platform, account and setup requirements. Consult the public release notes for what was checked and what remains unverified.

How do I report a problem or contribute?+

Use the GitHub repository to report an issue, suggest a feature or contribute code. Include your app version, operating system and steps to reproduce. Review an update’s release notes and back up your library before installing.
