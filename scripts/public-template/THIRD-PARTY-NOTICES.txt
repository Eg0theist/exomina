Voice previews: off until the user chooses Settings > Voice > Add voice previews. Exomina
then copies the voice recordings from the user's own installed OpenAI Codex and Anthropic
Claude desktop apps into the user's private Exomina data folder and builds a tonal-EQ
version of the ChatGPT recordings locally. The recordings remain OpenAI's and Anthropic's;
they are not uploaded or shared by Exomina, and only the apps' sound files are read.

Claude plan connection: off by default. If the user turns it on, Exomina uses the
user's own unmodified Claude Code, installed from Anthropic with Anthropic's
official installer. Anthropic's terms govern that software and the user's Claude
account.
