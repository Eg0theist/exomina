# Feedback

Open an Issue in this private repository. For a bug, include:

- Exomina version, operating system version and processor and what you were trying to do.
- The connection/model involved, without account identifiers or credentials.
- Steps to reproduce, expected behavior and what happened instead.
- A screenshot or exact error with private chat content and sensitive details removed.

Installation feedback is especially useful: installer behavior, recovery setup, first sign-in, first reply, update and uninstall. Also report confusing controls or missing onboarding guidance.

Do not attach account folders, browser profiles, API keys, login/device codes, session tokens, recovery keys/passwords or full conversation databases. Diagnostic files can contain private information; review and redact them before sharing. No automatic diagnostic upload is enabled.
